# Ecommerce Project

This project is currently a work in progress.

The goal of this project is to build an ecommerce application while learning and improving my backend and frontend development skills. It is being developed with Spring Boot for the backend and React for the frontend.

This project is also part of my learning process, so the codebase, structure, and features may change over time as I study better practices and add new functionalities.

Current focus:

* Backend API development
* Frontend integration
* Ecommerce features implementation
* Learning software architecture and development practices

More information and documentation will be added in the future.
